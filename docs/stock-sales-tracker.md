# TCS UMKM Stock & Sales Tracker

**Terakhir ditinjau: 2 November 2026**

## Ringkasan

TCS UMKM Stock & Sales Tracker adalah aplikasi desktop Windows yang dirancang untuk membantu pelaku usaha kecil mencatat persediaan dan aktivitas penjualan.

## Penyimpanan data

Rancangan produk Basic yang terdokumentasi menggunakan penyimpanan lokal pada perangkat. Pengguna bertanggung jawab menjaga keamanan perangkat dan membuat cadangan data secara berkala. Jangan menganggap data tersinkron ke cloud kecuali fitur tersebut dinyatakan secara eksplisit pada edisi yang digunakan.

## Edisi dan pembelian

Edisi Basic pernah ditetapkan dengan harga rencana Rp100.000. Harga tersebut merupakan catatan rencana sebelumnya, bukan jaminan harga transaksi saat ini. Periksa penawaran aktif di Projects.co.id atau kanal penjualan resmi sebelum membeli.

## Distribusi

Paket pembelian ditujukan untuk memuat aplikasi Windows beserta README/petunjuk pengguna. Pembeli tidak perlu mengunduh source code dari repositori pengembangan publik.

## Persyaratan dan kompatibilitas

Persyaratan Windows yang tepat harus mengikuti informasi pada halaman penawaran dan paket rilis produk. Jangan mengasumsikan dukungan untuk semua versi Windows tanpa verifikasi.

## Cadangan dan keamanan data

- Simpan salinan cadangan di lokasi terpisah dari perangkat utama.
- Jangan membagikan file database yang berisi data pelanggan atau transaksi.
- Pastikan ekspor dan pemulihan cadangan berhasil sebelum menghapus data sumber.
- Jika perangkat rusak atau aplikasi dihapus, data lokal mungkin ikut terdampak apabila tidak ada cadangan.

## Dukungan

Sertakan nama produk, versi aplikasi, versi Windows, dan uraian kendala saat menghubungi dukungan. Hapus atau samarkan data pelanggan sebelum mengirim tangkapan layar atau berkas diagnostik.

## Mesin pencari dan Googlebot

Repositori ini bersifat publik. Halaman Markdown yang tersedia melalui GitHub dapat ditemukan dan dirayapi oleh mesin pencari jika memenuhi kebijakan dan sistem pengindeksan mereka.

Hal yang perlu dipahami:

1. TCS tidak mengendalikan file `robots.txt` pada domain `github.com`. Menambahkan file bernama `robots.txt` ke repositori ini tidak akan mengubah aturan crawler untuk seluruh GitHub.
2. Google menentukan sendiri kapan sebuah halaman dirayapi dan apakah halaman tersebut layak diindeks.
3. Sitemap dapat membantu Google menemukan URL pada situs yang dikelola pemiliknya, tetapi bukan jaminan indeksasi.
4. Perubahan pada dokumen tidak menjamin hasil pencarian diperbarui seketika.
5. Informasi publik sebaiknya ditautkan secara jelas dari situs resmi TCS agar pengguna dan crawler dapat menemukannya.

Rujukan resmi Google:
- https://developers.google.com/search/docs/crawling-indexing/robots/intro
- https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview

# Privasi dan Keamanan

**Terakhir ditinjau: 2 November 2026**

## Prinsip umum

TCS berupaya merancang produk dengan memperhatikan privasi dan keamanan. Pernyataan ini bukan sertifikasi keamanan, audit independen, atau jaminan bahwa setiap sistem bebas dari kerentanan.

## Data sensitif

Jangan mengirimkan informasi berikut melalui GitHub Issues, komentar publik, atau kanal yang tidak dirancang untuk data rahasia:

- Kata sandi dan kode OTP.
- API key, server key, client secret, token, dan kredensial.
- Data kartu pembayaran lengkap.
- Database yang memuat data pelanggan.
- Dokumen identitas atau informasi pribadi yang tidak diperlukan.

## Pelaporan kerentanan keamanan

**Jangan membuat laporan kerentanan yang belum diperbaiki sebagai GitHub Issue publik.** Hubungi thechocostudio@gmail.com dengan subjek yang jelas, misalnya "Laporan Keamanan TCS". Sertakan dampak dan langkah reproduksi secara bertanggung jawab tanpa mengeksploitasi data atau akun milik orang lain.

Jangan menyertakan secret aktif pada laporan. Jika secret terlanjur terekspos, segera cabut atau rotasi melalui penyedia layanan terkait.

## Penggunaan produk

Pengguna bertanggung jawab menjaga keamanan perangkat, memperbarui aplikasi, dan melindungi cadangan data. Ketentuan privasi spesifik suatu produk dapat berbeda dan harus dibaca pada produk atau layanan terkait.
